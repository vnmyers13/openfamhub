# Release v0.26

**Date**: 2026-06-13

## Changes

### Fixed
- **Wall display controls always visible**: Grid View, Cycling Panels, and Exit Display buttons are now always shown at the bottom of the screen instead of hidden on non-hover. This fixes the issue where touch screen wall displays couldn't access the controls.
- **Wall display cycling countdown**: The auto-advance countdown now updates in real-time using a proper interval-based timer instead of calculating at render time.
