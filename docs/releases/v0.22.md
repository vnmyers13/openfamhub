# Release v0.22 — Wall Display Enhancement

**Date:** 2026-06-12  
**Version:** 0.22  
**Docker Images:** vnmyers13/openfamhub-api:0.22, vnmyers13/openfamhub-web:0.22

## Summary

Redesigned the wall display layout with a new component architecture featuring 4 new React components and a thin composer pattern.

## Changes

### New Components
- **MenuWallPanel** — Today's meal planning display (breakfast, lunch, dinner, snack)
- **CalendarWallView** — 4 view modes (agenda, daily, weekly, monthly) with toggle buttons
- **ChoresWallPanel** — Pending/all toggle with color-coded status badges
- **AnnouncementsWallPanel** — 7-day filtered announcements with max 5 display

### Layout Changes
- Top row (25vh): Announcements | Weather | Menu
- Bottom area (75vh): Calendar (70%) | Chores (30%)
- WallDisplay refactored into thin composer
